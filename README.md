# UV Move - Proof of Concept (PoC)

Sistema de movilidad universitaria desarrollado como Prueba de Concepto (PoC), integrando un frontend en React y una base de datos relacional IBM Db2 ejecutándose mediante contenedores Docker.

## 🚀 Stack Tecnológico

* **Frontend:** React (Vite)
* **Backend:** Node.js, Express
* **Base de Datos:** IBM Db2 (Docker)
* **Autenticación / Mapeo:** Supabase Auth (UUIDs)

---

## 📋 Requisitos Previos

Asegúrate de contar con las siguientes herramientas instaladas en tu equipo (entorno probado en Linux Mint/Ubuntu):

* [Docker](https://www.docker.com/) y Docker Compose
* [Node.js](https://nodejs.org/) (Versión 22.x recomendada)
* [Git](https://git-scm.com/)

---

## ⚙️ Guía de Instalación y Réplica

Sigue estos pasos en orden para levantar el proyecto completo de manera local:

### 1. Clonar el repositorio
Abre tu terminal y clona este repositorio en tu máquina local:
```bash
git clone [https://github.com/tu-usuario/uv-move-poc.git](https://github.com/tu-usuario/uv-move-poc.git)
cd uv-move-poc
realizar npm install (version mayor a 2.11)

para ejecutar el front realizar : npm run dev
